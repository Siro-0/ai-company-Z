# AI Company Core v2

外部通信・外部APIを使わない、ブラウザ内で動くルールベースの会社運営プロトタイプです。

## できること
- タスク登録とキーワードによる部署分類
- 優先度順に1件ずつ処理
- 大きなタスクを社長のルールで作業計画に分解
- 分解した作業を部署別タスクとして登録
- ブラウザ内保存、ログ表示、JSON書き出し
- v1形式の保存データを読み込む際の簡易移行

## まだできないこと
- 自由な推論を行うAIモデルによる判断
- インターネット上の市場調査や最新情報の取得
- 実際の商品制作、コードの自動変更、販売、決済
- ブラウザを閉じた状態での定期実行
- 複数端末間の同期

この版の「社長」は固定ルールで作業計画を作ります。実際の市場データや成果を理解しているわけではありません。

## 起動方法
`index.html` を直接開く方式では、ブラウザによってJavaScriptモジュールの読み込みが制限される場合があります。GitHub Pagesなどの静的ホスティング、またはローカルHTTPサーバーで開いてください。

## 注意
- 保存先はブラウザの localStorage です。ブラウザデータを消すと消失する可能性があります。
- 大切なデータは定期的にJSONで書き出してください。
- 金銭取引や外部システム操作は実行しません。
