# 自律型AI企業コア（試作版）

## 起動方法
`index.html` をブラウザーで開いてください。ブラウザーの制約でES Modulesが動かない場合は、同じフォルダーをローカルHTTPサーバーで配信してください。

## 現在できること
- タスク登録
- キーワードによる担当部署の振り分け
- 1サイクルにつき1タスクを処理
- 実行ログと状態のブラウザー内保存
- JSON形式での状態書き出し

## 重要な制限
これは自律型AIそのものではなく、外部通信をしないルールベースの土台です。市場の実データ取得、自然言語による高度な推論、コードの自動変更、販売や決済はまだ行いません。タスク処理結果はテンプレートです。

データはこのブラウザーの `localStorage` に保存されます。ブラウザーのデータ消去や別端末への移行に備え、定期的にJSONを書き出してください。
